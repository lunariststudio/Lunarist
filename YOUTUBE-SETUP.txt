AUTOMATIC YOUTUBE TITLE + DESCRIPTION

This build fetches the real YouTube title and full description automatically using the YouTube Data API v3.

For Vercel:
1. Create a YouTube Data API v3 API key in Google Cloud.
2. In the Vercel project, open Settings -> Environment Variables.
3. Add:
   YOUTUBE_API_KEY = your_api_key
4. Redeploy.

The API key stays server-side in /api/youtube.js and is not exposed in the page source.

Without the API key, the site falls back to YouTube oEmbed for the title, but YouTube oEmbed does not provide descriptions.
